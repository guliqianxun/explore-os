### 静态自检（人工 + 类型推演）

按 `tsconfig.json` 的 strict + noUnusedLocals + noUnusedParameters 反复 review，
逐项确认：

1. **类型契约**：`PaperListItem` 字段名严格匹配 `ft-028.md#dto-contracts`
   （`arxiv_id / paper_key / title / status / tags / n_comments / n_sections /
   n_figures / n_tables / n_claims`）。`CommentDTO` / `BacklinkDTO` /
   `BacklinkEdge` 同样照搬。
2. **导入循环**：`api/papers.ts` 从 `@/types/paper` 拉 type-only import；
   `types/paper.ts` 不反向引用 api，无环。
3. **TanStack Query v5 API**：`isPending`（不是 v4 的 `isLoading`）、
   `getQueriesData<T>()` 返回 `[QueryKey, T | undefined][]`、
   `setQueryData<T>(key, updater)`、`invalidateQueries({ queryKey })`、
   `cancelQueries({ queryKey })` 全部 v5 签名。
4. **react-router-dom v6.26**：`useSearchParams()` → `[URLSearchParams,
   SetURLSearchParams]`；`setSearchParams(URLSearchParams, { replace: true })`
   合法。`<Link to="...">` 不变。
5. **noUnusedParameters**：`onError(_err, _next, ctx)` 用下划线前缀（TS 规则
   允许）。所有局部 destructure 全部有用（`for (const [key, items]` 中 `key`
   被 `JSON.stringify(key)` 消费）。
6. **`React.MouseEvent`**：原本写 `React.MouseEvent` 会触发"Cannot find
   namespace 'React'"，已改为 `import type { MouseEvent } from "react"`。
7. **可选字段兜底**：wire 层 `Partial<PaperListItem> & Pick<arxiv_id, n_*>`
   + normalizer 写默认值（status 默认 `new`、title 默认 arxiv_id），
   即便后端 ft-028 schema 未上线也不会运行时炸。

如主会话代跑出现 TS error 请回报，一般会落在以下两点（先验排查）：

- `setQueryData(JSON.parse(serialized) as readonly unknown[], items)`：v5 接受
  `QueryKey = readonly unknown[]`，断言后类型应吻合。如 strict 报警可改为
  `as QueryKey`（需 `import type { QueryKey } from "@tanstack/react-query"`）。
- `BacklinkEdge` 在 `api/papers.ts` 既 `import type` 又 `export type`，
  `isolatedModules` 模式下需 type-only re-export — 已用 `export type {...}`
  形式。

## 偏离 / 风险

1. **未跑 build / tsc**：见 §npm build 节，沙箱限制；主会话需补跑。本人按
   strict TS / TanStack v5 / react-router v6 API 逐文件 review，如 0 error
   则功能完整；若有 error 大概率落在 `setQueryData` 的 `QueryKey` 类型断言。

2. **counts 双查询**：dsp-012 没规定 counts 怎么来，spec 也没对应 endpoint。
   现策略 = 始终额外发一次 `listPapers({status:"all"})`，前端 bucket。
   单用户桌面下 papers ≤ 几百，单次拉无成本；后端如果后续加
   `GET /api/papers/counts/` 可直接换实现，组件 props 不变。

3. **`Read` chip 双拉**：当前 `Promise.all([read_kept, read_dropped])` 两次
   网络。spec 明确说"backend 实现支持 `status=read` 聚合则替换"。后端
   subagent 若加这个 query value，把 `fetchPapersForFilter` 里的分支换掉
   即可（其它代码不动）。

4. **乐观更新回滚**：`onError` 用 `JSON.stringify(key)` 序列化 cache key 做
   reverse map。tanstack 的 `QueryKey` 都可以 JSON 化（不含 function/Symbol），
   当前所有 key（`["papers"]` / `["papers", filter]` / `["papers", "all"]`）
   都是纯字面量，安全。

5. **`paper_key` 空字符串**：normalizer 在后端字段缺失时填 `""`；
   `VerdictActions` 用 `paper.paper_key || paper.arxiv_id` 兜底，仍走老 URL
   到 `/api/papers/<arxiv_id>/status/`。后端 ft-028 spec 已确认双 id 路由
   解析（arxiv_id regex 与 `[A-Z2-9]{8}` 不重合）。

6. **PaperCard / HeroPaperCard 的 Link 拆分**：原版整张 article 都包在 Link
   里，按钮一点就触发跳转。本次把 Link 缩到标题区 + 缩略图区，
   `<VerdictActions>` 自身额外 `e.preventDefault()/stopPropagation()`
   做双保险。a11y 上 thumbnail Link 加 `aria-hidden + tabIndex={-1}` 避免
   重复 tab 焦点。

7. **未触碰 `IngestPage` 内部 mock**：dsp-012 黑名单内，与本任务无关。
