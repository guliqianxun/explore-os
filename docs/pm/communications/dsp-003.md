## DoclingExtractor 实现要点

```python
# apps/extract/extractors/docling_ext.py
from __future__ import annotations
from pathlib import Path
from threading import Lock
import torch
from docling.datamodel.base_models import InputFormat
from docling.datamodel.pipeline_options import (
    AcceleratorDevice, AcceleratorOptions, PdfPipelineOptions,
)
from docling.document_converter import DocumentConverter, PdfFormatOption
from apps.extract.base import (
    Extractor, ExtractResult, SectionMaterial, FigureMaterial,
    TableMaterial, EquationMaterial, CitationMaterial, make_material_id,
)

_CONVERTER: DocumentConverter | None = None
_CONVERTER_LOCK = Lock()

def _get_converter() -> DocumentConverter:
    global _CONVERTER
    if _CONVERTER is not None:
        return _CONVERTER
    with _CONVERTER_LOCK:
        if _CONVERTER is None:
            opts = PdfPipelineOptions()
            opts.images_scale = 2.0
            opts.generate_picture_images = True
            opts.do_formula_enrichment = True
            opts.accelerator_options = AcceleratorOptions(
                num_threads=8,
                device=AcceleratorDevice.CUDA if torch.cuda.is_available() else AcceleratorDevice.CPU,
            )
            _CONVERTER = DocumentConverter(format_options={
                InputFormat.PDF: PdfFormatOption(pipeline_options=opts),
            })
    return _CONVERTER

# Paper-level cache (避免 façade 多次调用导致多次 convert)
_DOC_CACHE: dict[str, "DoclingDocument"] = {}

def _convert(arxiv_id: str, pdf_path: Path):
    if arxiv_id in _DOC_CACHE:
        return _DOC_CACHE[arxiv_id]
    result = _get_converter().convert(str(pdf_path))
    _DOC_CACHE[arxiv_id] = result.document
    return result.document

class DoclingExtractor:
    def extract(self, paper_pdf_path: Path, paper_arxiv_id: str) -> ExtractResult:
        doc = _convert(paper_arxiv_id, paper_pdf_path)
        return ExtractResult(
            sections=_map_sections(doc, paper_arxiv_id),
            figures=_map_figures(doc, paper_arxiv_id),
            tables=_map_tables(doc, paper_arxiv_id),
            equations=_map_equations(doc, paper_arxiv_id),
            citations=_map_citations(doc, paper_arxiv_id),
        )
```

## 5 类 Material 映射规则

### Section
- 来源：`doc.texts` 中 `label == "section_header"`
- `material_id`: `<arxiv_id>:section:<seq>`，seq 按文档顺序从 1
- `path`: `t.text`（如 "3.2 Method: LeWorldModel"）
- `level`: `getattr(t, "level", 1)` —— docling 有些版本没此字段，安全获取
- `raw_text`: 暂留空字符串（v0.7 解读器需要时再补）
- `char_offset_start/end`: 暂 0/0（同上）

### Figure
- 来源：`doc.pictures`
- `material_id`: `<arxiv_id>:figure:<seq>`
- `page`: `p.prov[0].page_no` 若无则 0
- `bbox`: `[bbox.l, bbox.t, bbox.r, bbox.b]`（注意 docling 是 `BOTTOMLEFT` 坐标系，照存即可，下游若需要再转）
- `caption`: `p.captions[0].resolve(doc).text` 若无则 ""
- `fig_label`: 从 caption 文本头部抽 `Figure\s+\d+|Fig\.?\s+\d+`，无则 ""
- `image_path`: 调 `p.get_image(doc).save(<media/figures/<arxiv_id>/<material_id>.png>)`
- 跳过 image 为 None 的（不写 figure material —— 无图就不算 figure）

### Table
- 来源：`doc.tables`
- `material_id`: `<arxiv_id>:table:<seq>`
- `caption / bbox / page` 同 Figure
- `tbl_label`: 从 caption 抽 `Table\s+\d+`
- `raw_text`: `t.export_to_markdown(doc)` —— 不同版本 API 可能是 `export_to_markdown()` 或 `export_to_markdown(doc)`，try/except 兼容

### Equation
- 来源：`doc.texts` 中 `label == "formula"`
- `material_id`: `<arxiv_id>:equation:<seq>`
- `latex_or_text`: `t.text`（已是 LaTeX）
- `inline_or_display`: 默认 `"display"`（docling 不区分 inline/display，先全标 display）
- `eq_label`: None
- `page`: `t.prov[0].page_no` 若无则 0
- `bbox`: `t.prov[0].bbox` 若无则 None

### Citation
- 来源：扫 `doc.texts` 找首个 `label == "section_header"` 且 `text.lower()` 含 `"reference"`，之后的 `list_item` 全部作为 citation 直到下一个 section_header
- `material_id`: `<arxiv_id>:citation:<seq>`
- `raw_text`: list_item.text（完整原文）
- `bibkey`: 从 raw_text 启发式抽（首个作者姓 + 年份），抽不到留 ""
- `year`: 启发式抽 `\b(19|20)\d{2}\b` 第一个匹配
- `title`: MVP 不抽（spec 已说仅 bibkey + year + raw_text）
