### 2. resolve_pdf_path() helper

```python
# apps/papers/paths.py 加（或新建文件）
def resolve_pdf_path(paper: Paper) -> Path | None:
    if paper.pdf_path and Path(paper.pdf_path).exists():
        return Path(paper.pdf_path)
    if paper.arxiv_id:
        for d in (papers_dir(), pdf_legacy_dir()):
            p = d / f"{paper.arxiv_id}.pdf"
            if p.exists():
                return p
    return None
```

### 3. ingest 自动填充 pdf_path

### 4. PDF serve endpoint

```
GET  /api/papers/<id>/pdf/      # FileResponse application/pdf 或 404
HEAD /api/papers/<id>/pdf/      # 仅 200/404 探测，无 body
```

实现：

```python
class PaperPdfView(APIView):
    def get(self, request, id_or_key: str):
        paper = resolve_paper(id_or_key)
        path = resolve_pdf_path(paper)
        if path is None:
            return Response({"detail": "pdf not available"}, status=404)
        return FileResponse(open(path, "rb"), content_type="application/pdf")

    def head(self, request, id_or_key: str):
        paper = resolve_paper(id_or_key)
        path = resolve_pdf_path(paper)
        return HttpResponse(status=200 if path else 404)
```

注：`<id>` 双解析复用既有 `resolve_paper()`（ft-028 已有）。Range request **本派单不做**（ft-029 spec §风险 4 已记）。
