## 主会话修的 2 个 backend agent bug

1. **PAPER_KEY_ALPHABET 含 I/O**（违反 spec `[A-Z2-9]` 排除 0/1/I/O）
   - agent 写：`"ABCDEFGHIJKLMNOPQRSTUVWXYZ23456789"`（34 char，含 I/O）
   - 主会话改：`"ABCDEFGHJKLMNPQRSTUVWXYZ23456789"`（32 char，Zotero 风格）
   - 影响：`test_gen_key_charset_and_length` 偶发失败（依赖于 random key 是否抽到 I/O）
2. **PaperTagListView POST 重复 tag 没用 `transaction.atomic` 包**
   - agent 写：`try: UserTag.objects.create(...); except IntegrityError: ...`
   - pytest 外层 transaction（test runner 包的 atomic）被 IntegrityError 标 broken；后续 query 触发 `TransactionManagementError`
   - 主会话改：`with transaction.atomic(): UserTag.objects.create(...)` 隔离失败
