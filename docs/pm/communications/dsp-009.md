- 默认进入 PaperDetail：抽屉 closed，markdown 单栏居中（max-w 720px），衬线大字
- 右下角圆形按钮 toggle ClaimDrawer
- 左下角圆形按钮触发 FloatingTOC（浮 popover）
- ReadingModeToggle 在右上角，点击：隐藏 toolbar / 隐藏 toggle 按钮 / 全宽 markdown
- 抽屉打开时占用右侧空间，markdown 自动 shrink（仍居中 prose width）
- 抽屉内 ClaimCard 用 `max-w-[540px]`，padding 充足，公式 / counter_signal 不再局促

## ClaimCard 抽屉版样式

- 卡片之间 gap 24px（呼吸感）
- 头部：claim_type badge + confidence + page hint，柔和淡色（不要鲜艳）
- 正文：衬线小号（0.95rem），行高 1.65
- equation：KaTeX BlockMath 上下间距 12px，浅色 bg 卡 + 圆角
- counter_signal：`border-l-4 border-[var(--counter-fg)] bg-[var(--counter-bg)]`，italic 小字
- cite badges：圆角 chip，hover 浅 accent
