# Report: ft-041 记忆/编排双层 H0 完成

## 完成内容

- **Django app `apps/explore/`**: 新建，9 张 `explore_*` 前缀表
  - `ExploreVPState` (观点状态, per user×viewpoint)
  - `ExploreVPEvent` (追加事件日志, append-only)
  - `ExploreTopic` / `ExploreTopicEdge` (topic 分类法)
  - `ExploreActivity` (每日 A/C 快照)
  - `ExploreClaimLink` (观点交联)
  - `ExploreThread` / `ExploreThreadNote` (Echo 线程)
  - `ExploreOpenQuestion` (未决问题)

- **Signals** (3 个 handler, `apps/explore/signals.py`):
  - `UserPaperStatus.post_save` → unseen→exposed
  - `ExploreClaimLink.post_save` → confirmed→linked
  - `ExploreClaimLink.post_delete` → linked→confirmed

- **核心计算** (`apps/explore/activity.py`):
  - `compute_activity()` → A(t) 活跃度
  - `compute_consolidation()` → C(t) 固化度

- **Crunch 编排器** (`apps/explore/crunch.py`):
  - `run_crunch()` → 重算 A/C + 检测 gap + 写快照

- **API** (11 个 endpoint, `apps/explore/views.py` + `urls.py`):
  - `GET /api/state/profile/` / `activity/` / `gaps/` / `viewpoint/<id>/`
  - `POST /api/state/events/` / `links/` / `threads/` / `threads/<id>/notes/` / `questions/`
  - `DELETE /api/state/links/<id>/` / `questions/<id>/`

- **Management commands**:
  - `python manage.py seed_topics`
  - `python manage.py crunch`

- **Tests**: 14 个 (models×4, signals×3, activity×2, api×5) — 全部通过
- **重命名**: hermes → explore-os (文件夹、类名、表名、URL、imports、log)
