## Frontend 详设

### SubscriptionPage（重写）
```tsx
<div>
  <header>Subscriptions <Button onClick={openNew}>+ New</Button></header>
  {subs.map(s => <SubscriptionCard key={s.name} sub={s} onEdit={...} onRun={...} />)}
  <SubscriptionEditor open={...} sub={editing} onSave={...} />
</div>
```

### SubscriptionCard
显示：name (serif heading) / interests chips / sources (✓ list) / schedule / delivery / 上次运行时间。卡片右上角 [⚙] [▶ Run now]。

### SubscriptionEditor (modal)
- Name: input
- Interests: ChipInput（按 enter 加 chip，可点 X 删）
- Sources: 几个固定 checkbox（arXiv / HF Papers / GitHub 占位）+ arXiv 的 categories 子输入
- Schedule: radio (Daily / Weekly / Custom cron) + time picker
- Delivery: email input + outbox-only radio
- Advanced: 折叠面板，textarea YAML（双向同步：表单变 → yaml 重生成；yaml 变 → 表单 disable 提示）

### IngestPage (取代 RunPage)
```tsx
<div>
  <h1>Ingest a paper</h1>
  <IngestDropzone onUpload={...} />
  <Divider>or paste arXiv id</Divider>
  <Input placeholder="2401.12345" /> <Button onClick={fetchArxiv}>Fetch</Button>
  <Divider>or from URL</Divider>
  <Input placeholder="https://arxiv.org/pdf/..." /> <Button onClick={fetchUrl}>Fetch</Button>

  <h2>In progress</h2>
  {jobs.map(j => <IngestProgressItem key={j.id} job={j} onRead={...} />)}
</div>
```

### IngestProgressItem
3 阶段进度：✓ Extracted (33s/19f) ✓ Interpreted (10c/5s) ⏳ Rendering...
完成后显示 [Read →] 跳 PaperDetail。

### App.tsx
- 路由 `/run` → `/ingest`，组件指向 IngestPage
- 顶部 nav label: "Run" → "Ingest"
