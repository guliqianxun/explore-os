## DTO contracts（**直接拷贝使用，不要改字段名**）

```ts
// PaperListItem (扩展)
export interface PaperListItem {
  arxiv_id: string;            // legacy, 保留
  paper_key: string;           // [A-Z2-9]{8}
  title: string;
  status: PaperStatus;
  tags: string[];
  n_comments: number;
  n_sections: number;
  n_figures: number;
  n_tables: number;
  n_claims: number;
}

export type PaperStatus =
  | "new" | "queued" | "reading"
  | "read_kept" | "read_dropped" | "archived";

// CommentDTO
export interface CommentDTO {
  id: number;
  text: string;
  created_at: string;          // ISO
  hidden: boolean;
}

// BacklinkDTO
export interface BacklinkDTO {
  outgoing: BacklinkEdge[];
  incoming: BacklinkEdge[];
}
export interface BacklinkEdge {
  id: number;
  src_key?: string; src_title?: string;   // 仅 incoming 填
  dst_key?: string; dst_title?: string;   // 仅 outgoing 填
  relation: string;
  note: string;
  created_at: string;
}
```

## 组件 1：`VerdictActions.tsx`

```tsx
interface Props {
  paper: PaperListItem;     // 用 paper_key（优先）或 arxiv_id 调 API
  onChanged?: () => void;   // 让父级 invalidate 查询
}
```

3 个按钮：

- **[Skip]** → setPaperStatus → "read_dropped"
- **[Queue]** → setPaperStatus → "queued"
- **[Read now]** → setPaperStatus → "reading"，然后 `<Link to={'/papers/' + paper.arxiv_id}>` 跳详情页

样式 follow editorial tokens（small uppercase tracked-out + soft pastel）。
当前 status 高亮 / 灰禁用（如已 archived 则只显示 status，不显示 buttons）。

用 `useMutation` + `queryClient.invalidateQueries(["papers"])`。

## 组件 2：`StatusFilterBar.tsx`

```tsx
interface Props {
  current: PaperStatus | "all";
  counts: Partial<Record<PaperStatus | "all", number>>;
  onChange: (s: PaperStatus | "all") => void;
}
```

5 个 chip：`New (默认) / Queued / Reading / Read（read_kept + read_dropped 合并显示）/ All`，
counts 旁标。

注意：`Read` chip 内含两个 status，filter 时往 backend 发 `status=read_kept`
和 `status=read_dropped` 各拉一次再合并？或者 backend 接受 `status=read`？
**spec 没说**，frontend 暂用前者（两次拉合并）；如 backend 实现支持 `status=read`
聚合则替换。
