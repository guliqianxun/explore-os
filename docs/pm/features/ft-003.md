# ft-003 Source: arXiv

## 目标
按订阅 query 抓取 arXiv 最近 N 天新增 paper，作为首个 `SourceFetcher` 实现。

## 设计
- 定义通用接口 `SourceFetcher`：
  - `key`：标识（`arxiv`）
  - `group`：展示分组（`papers`）
  - `fetch(query, since, limit) -> list[Item]`
- 标准化输出 `Item`：`external_id / title / abstract / authors / venue / published_at / url / source_key / group / raw`
- arXiv 实现：官方 Export API（`http://export.arxiv.org/api/query`），按 query + categories + submittedDate 过滤。
- 限流：API 要求间隔 3s，内置退避。
- 本地落盘：抓到的原始 JSON 写入 `FetchRecord` 表（paper 维度去重靠 ft-005 的历史表，本表只做审计）。

## 验收
- `manage.py fetch_source arxiv --query "diffusion model" --since 7d` 返回结构化 Item 列表。
- 网络失败有重试、限流不触发封禁。
- Item 输出满足下游 rewriter/解读/渲染所有字段需要。

## 风险
- arXiv API 稳定性一般，需要足够的重试与日志。
