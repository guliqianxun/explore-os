# ft-018 微信订阅号 DeliveryAdapter

## 目标
让订阅可以推送到微信订阅号（公众号），发布为图文推文。
**这是产品化的主推送渠道**。

## 选型：订阅号 vs 服务号

| 维度 | 订阅号 | 服务号 |
|---|---|---|
| 群发频率 | **每天 1 次** | 每月 4 次 |
| 单次篇数 | 1-8 篇 | 1-8 篇 |
| 适合 | 内容日报 ✅ | 客户服务 |

→ **选订阅号**，每天 1 篇正文（含若干 paper）。

## 流程

```
1. access_token = POST .../cgi-bin/token?grant_type=client_credential
                       &appid=APPID&secret=SECRET                  # 缓存 ~2h
2. 上传封面图（thumb_media_id）= POST .../material/add_material?type=image
3. 上传正文图（拿到外链 url）= POST .../media/uploadimg
4. 创建图文草稿 = POST .../material/add_news
   body: { "articles": [{title, thumb_media_id, content (HTML), digest, ...}] }
5. (可选) 群发 = POST .../message/mass/sendall
   或 (推荐 MVP) 只创建草稿，让用户在公众号后台审核 + 一键发布
```

## HTML 受限白名单

微信图文 content 字段允许的标签是：
`<p> <strong> <em> <a> <img> <h1>-<h6> <ul> <ol> <li> <blockquote> <hr> <br>`
**不允许**：`<details>`、`<style>` block、外部 CSS、`cid:image`

所以 email_adapter 的 HTML 不能直接复用，需要**单独的 wechat_render**：
- 折叠英文原文 → 改为"附录" `<blockquote>` 简化
- inline 图必须替换 cid 为微信 cdn url（uploadimg 返回的）
- 内联样式可保留但效果有限

## Digest → 推文映射

```
Digest.subject               → article.title（最多 64 字符）
Digest.deeps[0].deep.figure  → article.thumb_media_id（封面图）
narrative + deeps + skims    → article.content（HTML）
Digest.run_summary           → article.digest（摘要，140 字内）
原文链接                     → article.content_source_url（"查看原文"）
```

如果一天的 deeps + skims 太多（比如 >5 篇），可以拆成 multi-article（订阅号支持单次最多 8 篇）。

## target.params 字段
```yaml
deliveries:
  - channel: wechat_subscription
    params:
      appid: wx_xxxxx
      appsecret: xxxxxxx
      mode: draft     # draft（推荐 MVP）| publish | preview
      preview_openid: o_xxxx   # 仅 mode=preview 用
```

## 关键风险

1. **接口审核**：每次 add_news 公众号后台会扫描内容；含敏感词或外链可能被拒
2. **图必须公网可访问**：uploadimg 返回的 url 才能用，本地 cid 不行
3. **服务器 IP 白名单**：公众号后台需配置允许调 API 的 IP（你的服务器 IP）
4. **草稿 vs 群发**：MVP 强烈建议 draft，避免误推全粉丝

## 工作量
- 1 天：access_token 管理 + 图上传流程
- 1 天：HTML 转换（去除 details / 替换 cid）+ add_news 调用
- 0.5 天：调试微信 quirks + 草稿在后台预览
- 总：~2.5 天

## 验收
- 注册测试公众号 + 配置服务器 IP
- 跑 `run_subscription` 创建草稿
- 公众号后台能看到草稿，封面图 + 内联图正常
- 文章预览阅读体验良好（手机上）
- 一键发布到全粉丝成功

## 不在范围（后续）
- 多公众号矩阵
- 自动定时发布（依赖 cron 或自带 scheduler）
- 自动回复 + 关键词触发查询
