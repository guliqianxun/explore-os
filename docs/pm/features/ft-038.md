# ft-038 i18n 双语 + Settings 页发布前清理

## 触发

ft-037 立项后用户实测，发现两件事：

1. Settings 页"无用说明太多"——大量 hint 文案是给开发者看的（`覆盖 .env`、
   `dedup_key 计算`、`分发安装包不会带走它` 等），干扰发布形态。
2. 需要"统一配置语言选项"——双语支持。Subscription / Ingest / 论文卡按钮
   等关键路径文案都还是英文 / 英中混排。

## 决策（2026-05-01 lock）

1. **i18n scope 仅覆盖 UI chrome**：导航 / 按钮 / 字段标签 / 状态徽章 /
   空状态。**LLM 生成内容（abstract_zh / brief / claim / for_you）保持
   原语**——LLM 原本就是按 user perspective 跑的中文输出，硬翻只会损失。
2. **react-i18next** 作为运行时（行业标准；支持插值 / fallback / browser
   detector），运行时 ~60KB（gzip 后 ~20KB）可接受。
3. **持久化走 localStorage**（key `explore-os.lang`），不进 SQLite，不与
   sidecar 通信——纯前端关心。
4. **默认 fallback `zh`**，detect 优先级：localStorage > navigator
   语言。
5. **Settings 页砍掉所有冗余说明**：移除 SourceBadge（"user_config.json /
   .env / 默认"）、底部"字段未填→回落..."footer、绝大多数 hint。保留
   非显然字段的极简提示（Deep model = "留空 = 使用文本模型"）。

## 范围

### A. i18n 框架
- 安装 `i18next` + `react-i18next` + `i18next-browser-languagedetector`
- 新文件 `frontend/src/i18n/index.ts`：bootstrap + `setLang()` / `currentLang()` 暴露
- 字典 `frontend/src/i18n/locales/{zh,en}.json`，按 namespace 组织（`nav.*`、
  `common.*`、`settings.*`、`subs.*`、`ingest.*`、`papers.*`、`notifications.*`）
- 入口 `main.tsx` import `./i18n` 触发 init

### B. 翻译覆盖（这一刀）
| 区域 | 文件 |
|---|---|
| NavBar | `App.tsx` |
| 桌面通知文案 | `hooks/useJobPolling.ts` (`i18n.t` 直调) |
| 今日要览 | `pages/PaperListPage.tsx` + 三段桶 sub-header |
| 订阅页 | `pages/SubscriptionPage.tsx` + `components/SubscriptionCard.tsx` |
| 导入页 | `pages/IngestPage.tsx` + `components/IngestDropzone.tsx` |
| 论文卡按钮 | `components/VerdictActions.tsx` (Skip/Queue/Read now) |

| 3 标签卡 | `components/PaperCard.tsx` (Materials/Claims/AI Summary + 摘要 + 中文翻译 toggle) |
| 详情卡片切换 | `HeroPaperCard.tsx` / `SkimCard.tsx`（▸ 显示中文翻译）|

### C. Settings 页重写
- 三大 SectionGroup：通用（语言）/ LLM / 数据目录
- 砍掉 SourceBadge / footer 段 / 大部分 hint
- 语言切换器：两个按钮（中文 / English），点击立即生效 + 写 localStorage
- 接 ft-037 DataDirSection（同样使用 i18n）

### D. 不在范围
- ❌ Subscription Editor 表单（信源 / 渠道 / 调度大表，专业术语不翻）
- ❌ Reading Station / PaperDetailPage 内容区
- ❌ ActiveRunsBanner / IngestProgressItem 状态条（pending/running/done 跨语言通用）
- ❌ 后端 API error message（前端 alert 已 wrap 在 t()）
