# ft-036 First-user trial polish

iter-019 收尾后的「**首位用户实测 → 调路径**」一刀。覆盖 5 块改动：

## 1. Electron 真启 blank fix（HashRouter）

**真回归**：iter-019 没在 prod-mode（loadFile file://）实跑，`BrowserRouter`
拿到的 pathname 是 `/E:/.../index.html`，无 Route 命中→整页空白无报错。
切到 `HashRouter` 解决；URL 形如 `file:///.../index.html#/papers`。
（commit `8175407`）

## 2. paper.keywords 字段 + 编辑层

**Why**：之前 list DTO `keywords` 字段语义模糊（实际是 brief.keywords / LLM 抽
的）。新 `Paper.keywords` JSONField 表示**作者上传**的 keywords，与 LLM 抽的
brief.keywords 解耦。

落地：

- `Paper` 加 `keywords` JSONField（migration 0007） + DTO 暴露
- `POST /api/papers/<id>/keywords/` 覆盖式更新；norm: trim / 64-char cap /
  20-item cap / case-insensitive dedupe
- `KeywordsEditor` 组件：read-only chip → Edit → input + Enter 加 / × 删 /
  Save invalidate query
- 挂在 SpeedReadView BriefSection 上方

（commit `36b37a0`）

## 3. 卡片墙报式 + 信息密度迭代

**Why**：第一版卡片 abstract 太长堵满视野，缩略图与文本互相挤；用户期待密度
更高 + 图文绕排（"墙报式"）+ 一眼能看到关键词。

落地：

- HeroPaperCard / PaperCard：figure float-right 让 title / abstract 绕图；
  clear-both 后挂 3 个 meta tab（Materials / Claims / AI Summary）。点 tab 展
  开 panel（react-query 缓存 60s 拉 detail）
- SkimCard 升级：title + keywords + 原文 abstract（不截断）+ ▸ 中文翻译
  toggle；不挂图 / 3 cards
- list DTO 加 `brief_keywords` 字段：精读卡的 chip 主源 paper.keywords > 空
  fallback brief.keywords (LLM)；速度卡仅 paper.keywords（不展示翻译版）
- 默认显示**原文 abstract**（英文），中文翻译走 `▸ Show 中文翻译` toggle

（commits `76b1525`, `d24562b`）

## 4. 订阅 → Paper feed 桥

**Why**：legacy `run_subscription` 走 email + memory，**不写 Paper 表**。
配置好订阅、跑完，前端 brief feed 不见 paper。

落地：

- 新加 `apps/llm/services/subscription_persist.py` —— SkimOut/DeepOut 直接落
  Paper + PaperBrief；不替代 brief_generator（detail 页 canonical 路径仍走
  docling Section 的 brief_generate）
- `run_subscription` step 7.5 调桥；`--no-persist` 可关
- `run_subscription deliveries=[]` 改 warn 不再 raise（trial 不发 email）
- `run_subscription` 加 `--days N` 放大单天窗口
- 测试隔离：`conftest.py` autouse fixture 把 `SUBSCRIPTIONS_YAML` 默认指到
  tmp_path，防真 yaml 漏进 perspective fixture

**首位用户实测结果**：
- 配两条订阅：`precip-nowcasting` + `video-generation`，deliveries=[]
- 跑 `--no-deep --days 30` 共 14 篇 paper 落库（2 + 12），耗时 ~70s
- 前端 brief feed 全部可见，AI Summary tab 可看 brief.method_summary_zh /
  key_innovation / for_you

（commit `9135183`）

## 5. 外链 arXiv ↗ + PDF ↓

**Why**：用户要求每张卡能跳 arxiv 网页 + 下载 PDF。

落地：

- `PaperLinks` 组件：仅对 arxiv 模式 ID 渲染（`\d{4}\.\d{4,5}` 新式 + 老式带
  子分类）；上传 PDF 的 sha256-id 不出按钮
- Electron IPC `explore:open-external`：main.ts 走 `shell.openExternal`，限
  https?:// 协议防 LFI；preload 暴露 `window.explore.openExternal`
- 浏览器 dev 回退 `window.open(url, "_blank")`

（commit `2d4c6bf`）

## 环境配套

- `socksio` 加进 pyproject + uv.lock：dev 机带 `ALL_PROXY=socks5://...` 时
  httpx 起 SOCKS 不再 ImportError （commit `beaf18b`）

## 决策记忆

写入 `memory/subscription_speed_vs_precision.md`：**订阅链=快粗（skim+
brief，~70s/12 篇）；detail 阅读=慢精（docling 抽 sections + figures + claim
L1/L2，按需触发）**。任何把 docling 塞进订阅链的方案都违反这个意图。
