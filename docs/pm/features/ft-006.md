# ft-006 LLM TL;DR 解读

## 目标
对本次新增条目生成 TL;DR 级别解读，为 v0.2 的深度解读预留分档扩展点。

## 设计
- 接口：`Interpreter.interpret(item, depth) -> Interpretation`
- MVP `depth=tldr`：
  - 输入：title + abstract
  - 输出：1–2 句要点（≤ 60 字）+ 3 个关键词
- **缓存表 `Interpretation`**：`dedup_key + depth + model → 结果`，不同订阅共享命中。
- **预算守门**：订阅级或全局每日成本上限（配置化），触顶跳过该次解读（保留原 title/abstract 推送）。
- LLM 客户端：Django settings 读 API key，支持 OpenAI 兼容接口（方便换模型/供应商）。

## 验收
- 新 item 首次被看到 → 生成 TL;DR 并落缓存。
- 跨订阅命中缓存 → 0 LLM 调用。
- 成本累计写入 `SubscriptionRun.llm_cost_cny`。

## 后续（v0.2）
- `depth=deep`：结构化输出（背景/方法/结论/对比）。
- Prompt profile 按订阅覆写。
