# ft-037 PC 便携版 + 数据目录用户可配

## 触发

iter-021 / ft-031 落地后用户提出："这应用能做成不需要安装的吗？数据落盘
位置默认项目路径，可以用户自己配置。"

当前形态：electron-builder 出 NSIS 安装器（写 Program Files / 注册表），
数据强制落 `%APPDATA%/explore-os/`，用户改不了。便携场景（U 盘携带 / 解压
即用 / 多机切换）走不通。

## 决策（2026-05-01 lock）

1. **不做手机版**（Android / iOS）。理由：Python sidecar + docling/torch
   抽取链路在手机上跑不动；这条路是「重写」级别的代价，且违背 v1 锁定的
   「桌面 app 长期形态」约束（CLAUDE.md）。
2. **PC 便携版与现 NSIS 安装器并存**，不替换：分发渠道二选一，自用阶段
   优先便携。
3. **数据目录解析优先级**（高 → 低）：
   1. `user_config.json.data_dir`（用户在 Settings 页填写）
   2. `EXPLORE_OS_DATA_DIR` env（CI / 高级用户）
   3. **portable 模式**：`<exe 同目录>/data/`（electron-builder 注入
      `PORTABLE_EXECUTABLE_DIR` env，main 进程检测）
   4. 平台默认：`%APPDATA%/explore-os` / `~/Library/Application Support/explore-os` / `~/.config/explore-os`
4. **不自动迁移旧数据**：用户从 NSIS 装版切到 portable 时，旧数据留在
   `%APPDATA%`，新数据落新路径。手动迁移（拷贝目录）不在本范围。
5. **路径切换需重启**：sidecar 启动时定 `EXPLORE_OS_DATA_DIR`，运行时
   不能热切（避免半生不熟的 DB / 缓存切换）。Settings 页改完弹"已保存，
   重启应用生效"。

## 范围

### A. electron-builder portable target

**`electron/build/electron-builder.yml`**：
- Win `target` 加 `portable`（与 `nsis` 并列）→ 出 `explore-os-<ver>-portable.exe`
  单文件自解压 exe（~1.5GB CUDA bundle）
- Mac `target` 改为 `[dmg, zip]`：zip 形态是 portable
- Linux：AppImage 本身就是 portable，不动

### B. portable 模式检测 + 数据目录解析

**`electron/src/sidecar.ts`** 启动 sidecar 时，按上述优先级算 `dataDir`，
写入子进程 env `EXPLORE_OS_DATA_DIR`：

```ts
function resolveDataDir(): string {
  const userCfg = readUserConfig()?.data_dir;     // 1
  if (userCfg && fsCanWrite(userCfg)) return userCfg;
  const envOverride = process.env.EXPLORE_OS_DATA_DIR;  // 2
  if (envOverride) return envOverride;
  const portableDir = process.env.PORTABLE_EXECUTABLE_DIR;  // 3
  if (portableDir) {
    const dataDir = path.join(portableDir, "data");
    if (fsCanWrite(dataDir)) return dataDir;
  }
  // 4. 落 apps/core/paths.py 平台默认
  return platformDefault();
}
```

**Electron main 也同步把这个值写到 `app.setPath("userData", ...)`**，让
window state / cache 跟数据目录走（保证 portable U 盘单元化）。

### C. user_config.json 加 data_dir 字段

复用 commit 3699467 已有的 `user_config.json` 运行时分层。新增字段
`data_dir`（绝对路径字符串）；Electron main 读，sidecar 不直接读这个文件，
靠 main 通过 env 透传（保持 sidecar 路径解析单一入口）。

### D. Settings 页新卡：数据目录

**`frontend/src/pages/SettingsPage.tsx`**：
- 新增 `<DataDirSection>`：
  - 显示当前 effective `data_dir`（来自 `GET /api/health/` 或新加 `/api/system/data-dir/`）
  - "更改…" 按钮 → Electron `dialog.showOpenDialog({ properties: ['openDirectory'] })`
  - 选定后写 `user_config.json.data_dir`，UI 弹 toast "已保存，重启应用生效"
- "恢复默认"按钮 → 清空 `data_dir` 字段，回退到优先级链路 2/3/4

新 IPC：`explore:pick-directory()` → 调 `dialog.showOpenDialog`。
新 IPC：`explore:get-current-data-dir()` → 同步返回当前 main 进程算出来的 dataDir
（让 Settings 页不依赖 sidecar 也能显示）。

### E. README / 文档

`docs/pm/CHANGELOG.md` 加 v1.3 portable 一节；`README.md` 加便携版下载
说明（"双击 exe 即用，无需安装"）。

## 不在范围

- ❌ 手机版（Android / iOS） — 弃
- ❌ macOS / Linux 的 portable 体验改进（zip / AppImage 已 portable，不再加按钮）
- ❌ 数据迁移工具（手动复制目录够用）
- ❌ 多数据目录共存 / profile 切换（一个 app 一个 data_dir）
- ❌ 代码签名 / SmartScreen 申诉 — 自用阶段不签
- ❌ 热切数据目录（不重启） — 风险大于收益

| `npm run build:all` 产物 | `dist/explore-os-<ver>-portable.exe` 单文件，双击即跑 |

## 风险

- **portable exe 启动慢**：自解压到 temp，~1.5GB 解压第一次冷启 10s+。
  缓解：在 NSIS 版下提示"如果启动太慢，试试 portable / 反之亦然"。
- **Win SmartScreen**：未签名 portable exe 弹"不常见的应用"警告。自用阶段
  接受，公开分发延后到 v1.5（ft-025 双轨打包后再考虑签名）。
- **PORTABLE_EXECUTABLE_DIR 只 Win 注入**：Mac zip / Linux AppImage 拿不到
  这个 env，得各自识别（AppImage 走 `APPIMAGE` env，Mac zip 走 `process.execPath` 同目录探测）。
- **多实例 single-instance lock**：当前 `app.requestSingleInstanceLock` 用
  `app.getPath("userData")` 做 lock 文件位置；同步 `app.setPath("userData", <portableDataDir>/electron)` 后 OK。
- **数据目录路径含中文 / 空格**：sidecar 走 PyInstaller subprocess，env
  传字符串，需在 Windows 下确认 cp936 不会乱码（已知 ft-022 修过类似坑，
  按已有 pattern 处理）。
