# ft-010 Daily Narrative

## 目标
邮件顶部 2–3 句话跨篇合成，告诉用户"今天领域在聊什么"。
让日报不再是"论文清单"，而是"每天一个带叙事的切片"。

## 设计
- 输入：本次入选的所有 item 的 `one_liner + keywords + score`（即 ft-009 的 skim 输出）
- 一次 LLM 调用，system prompt 要求"找共同主题、数数、点名高分篇"
- 输出 3 条 JSON：
  ```json
  {
    "hero_sentence": "今日 9 篇中 4 篇围绕视频世界模型",
    "bullets": [
      "世界模型（#1 #3 #6 #8）：从单视角扩展到多智能体多视图",
      "推理加速（#4）：推测解码首次应用到自回归视频扩散",
      "数据/基准（#2 #5）：统一基准和合成数据增强"
    ],
    "note_for_you": "推荐先读 #1 #4（精读档已选中）"
  }
  ```
- 渲染到邮件头部的特殊区块，视觉醒目

## 失败降级
LLM 失败 → 不渲染 Narrative 区块，邮件正常发

## 视角
复用 ft-009 的 `perspective` 前缀，Daily Narrative 也按视角产出（研究者视角 vs 工程师视角的今日总结不一样）

## 文件范围
- `interpret/narrative.py`（新）
- `delivery/email_renderer.py`：加顶部 narrative 区块
- `run_subscription`：在略读解读后调一次 narrative

## 测试
- `tests_narrative.py`：mock LLM，验证输入格式、输出解析、失败降级

## 验收
- 实战视频生成订阅：顶部能出"今日主题：…"段落，抓住真实聚类（人工验）
- narrative 失败时邮件仍能发出
