# ft-002 Interest Rewriter

## 目标
把订阅 `interests`（自由文本/关键词混合）翻译成每个 source 能直接使用的 query 形式。

## 设计
- 接口：`Rewriter.rewrite(interests: list[str], sources: list[SourceKey]) -> dict[SourceKey, SourceQuery]`
- MVP 策略：**一次 LLM 调用**，prompt 让模型给各 source 产出：
  - arXiv：布尔查询串 + 建议 categories
  - HF Papers：关键词列表
- 结果**按 `hash(interests + sources + model)` 缓存到 DB**，订阅内容不变则不重算。
- 失败降级：直接把 interests 原样当关键词丢给各 source。

## 验收
- 对 `["diffusion model", "flow matching"]` 能输出合理的 arXiv query（人工抽查）。
- 同一订阅第二次运行命中缓存，不发起 LLM 调用。
- LLM 不可用时降级链路可跑完。

## 后续（v0.3）
- 按 source 独立 rewrite，支持 source 特定 DSL（GitHub topic、HF filter 等）。
- 引入 few-shot 示例库，质量提升。
