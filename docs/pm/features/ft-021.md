把 ft-020 的 `interpret_claims` / `interpret_counter_signals` 数据可视化为**单篇精读图谱**。

## PaperGraphModel（图谱抽象，apps/render/graph.py）

```python
@dataclass
class GraphNode:
    node_id: str                    # claim:1 / figure:3 / table:5 / citation:42
    kind: Literal["claim", "figure", "table", "citation"]
    label: str                      # 短文本（卡片正文）
    attrs: dict                     # extras: image_path / page / claim_type / confidence / etc

@dataclass
class GraphEdge:
    from_id: str                    # node_id
    to_id: str                      # node_id
    kind: Literal["supports", "contradicts", "cites", "illustrates"]
    label: str = ""                 # 可选边标签

@dataclass
class PaperGraphModel:
    paper_arxiv_id: str
    nodes: list[GraphNode]
    edges: list[GraphEdge]
```

## 节点设计（已 lock）

- `claim` 节点：rectangle，label = claim text 短摘要（≤ 40 字），attrs 含 claim_type / confidence
- `figure` 节点：image（嵌入 PNG），label = caption 头部 30 字，attrs.image_path
- `table` 节点：rectangle（表格 markdown 不嵌入，只显示 caption）
- `citation` 节点：仅当被某 claim cite 时入图（不入全部 57 条 reference），label = bibkey + year
- **不入图**：equation 节点（视觉过载，留在卡片内可点开）、section 节点（结构性元数据）

## 边设计（已 lock）

- `supports`：claim → figure / table / equation（来自 L1 claim_evidence，relation=supports/quantifies）
- `illustrates`：claim → figure（来自 L1 claim_evidence，relation=illustrates）
- `contradicts`：counter_signal 隐含的反向关系，画为 claim → counter_signal_text 边（counter_signal 不是单独节点，而是作为「红色批注边」标在被反驳的 claim 上）
- `cites`：claim → citation（仅当 claim 在原文段落中明确引用了该 prior work）

> 简化：counter_signals 不作为独立节点，而是作为带颜色批注的 edge attached to its claim。这样图谱聚焦 claim/evidence/citation 三类核心节点。

## 布局策略（MVP，简单分层）

- claim 节点排第一行（按 confidence 降序）
- 第二行 figure / table evidence
- 第三行 citation（如有）
- 边按 `from.y < to.y` 自然向下
- 不做力导向（Excalidraw 用户自己拖拽即可）

后续 v1.x 可考虑接入 dagre / elkjs 做自动分层布局。

## SVG fallback（兜底）

`apps/render/svg_renderer.py` 输出 `graph.svg`，纯静态可嵌邮件。MVP 简版：节点矩形 + 文字 + 直线箭头，不要求美观，只要求**没有 Excalidraw 的离线场景下也能看**。

## 数据流

```python
def build_graph(arxiv_id: str) -> PaperGraphModel:
    """从 interpret_* + extract_* 表组装抽象图谱。"""
    claims = Claim.objects.filter(paper_arxiv_id=arxiv_id).prefetch_related("evidences")
    counter_signals = CounterSignal.objects.filter(claim__paper_arxiv_id=arxiv_id)
    nodes, edges = [], []
    cited_materials = set()
    for c in claims:
        nodes.append(GraphNode(node_id=f"claim:{seq(c)}", kind="claim", label=c.text[:40], ...))
        for e in c.evidences.all():
            cited_materials.add(e.material_id)
            edges.append(GraphEdge(from_id=f"claim:{seq(c)}", to_id=short(e.material_id),
                                   kind="supports" if e.relation == "supports" else e.relation))
    for cs in counter_signals:
        # counter_signal 作为「contradicts」边，attached to claim → evidence
        edges.append(GraphEdge(...))
    # 只把被 cite 的 figure/table 加成节点
    for mid in cited_materials:
        kind = mid.split(":")[1]
        if kind in ("figure", "table"):
            nodes.append(...)
        elif kind == "citation":
            nodes.append(...)
    return PaperGraphModel(arxiv_id, nodes, edges)
```
