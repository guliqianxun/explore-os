# ft-013 caption-based 精读重设计 + 订阅记忆线

## 目标
1. 替换 ft-012 多模态分类路径——确定性的 caption/bbox 信号取代视觉模型猜测
2. 引入跨 run 的订阅级"记忆线"，让 deep_interpret 能联系昨日推送
3. 推送默认 target = 昨日（Asia/Shanghai），不再"近 N 天"窗口

## 设计原则（同步写入 CLAUDE.md）
> **确定性产出 → 工具化（代码 + 规则 + 缓存）**
> **需要语义理解 / 动态编排 → LLM**
> **LLM 是「填补」边界的，不是「替代规则」的**

caption 文本是作者亲自写的"这是什么图"，比视觉模型猜测准确得多，且 0 token 成本。
我们之前误把 caption 提取与图分类都丢给多模态 LLM——那是错位。

## 模块划分

### 工具化（确定性，零 LLM）
- `interpret/caption_extractor.py`：pymupdf 抽 caption（Figure/Fig./Table/Tab. 前缀），含 bbox + 引用上下文搜索
- `interpret/figure_picker.py`：先规则匹配（framework/overview/architecture/pipeline 关键词），落空回退 figure 1，再落空可选 LLM 文本兜底（不喂图）
- `sources/pdf_renderer.py`：`page.get_pixmap(clip=bbox)` 渲染对应 page 区域为 PNG，替代 `extract_image` 的矢量碎片
- `subscriptions/memory.py`：runs.jsonl / papers.jsonl / digests.md 三件套，按订阅 namespace 隔离

### LLM（语义）
- `interpret/deep_interpret.py` 改造为**纯文本 LLM**：输入 method/exp/conclusion 章节文本 + caption 列表 + 引用上下文 + memory 中近期推送的相关论文，产 `[Fig. N]` 锚点引用的四段输出

### 关停（保留代码）
- `interpret/figure_classifier.py`：不删；`run_subscription` 默认不调用，仅 `--multimodal-figures` 显式启用
- `interpret/figure_extractor.py`：仍可调用，但精读路径改用 bbox-render 不抽嵌入像素

### 时间窗
- `--target-date YYYY-MM-DD` 参数，默认昨日（Asia/Shanghai）
- fetcher 拉宽窗口；按 `published_at` 严格过滤到 [target_date, target_date+1) UTC

## 记忆线 schema

```
media/memory/<sub_name>/
├── runs.jsonl       # 每次运行一条 RunRecord
├── papers.jsonl     # 每篇推送过一条 PaperRecord（含 one_liner, keywords, score, tier）
└── digests.md       # 累积速览，按日期段落追加
```

- 跨 run 去重：同 dedup_key 的论文不再二次推送
- deep_interpret 上下文：读最近 8 条 paper records，让 LLM 能写"这是 #X 论文的延续/对照"

## 验收
1. 命令默认目标 = 昨日；--target-date 可覆盖
2. 二次跑同一日：所有论文被 memory 跳过 → "no items, exit early"
3. 精读篇：捕获 ≥1 个 caption；图选取走 keyword 命中；PNG 由 bbox 渲染（清晰完整、无矢量碎片）
4. deep_interpret 输出包含 `[Fig. 1]` 锚点；上下文里能看到上次相关论文的标题
5. 多模态调用计数 = 0（纯文本 LLM）
6. 全量 tests + 实战发件 OK

## 与 ft-012 的对比

| 维度       | ft-012（multimodal）        | ft-013（caption + bbox）     |
|------------|------------------------------|-------------------------------|
| 图分类     | qwen-vl-plus 每张 ~10s ~0.02 | 关键词正则瞬时 0 元           |
| 深度解读   | qwen3.6-plus 多模态 ~30s     | qwen-text 纯文本 ~10s         |
| 单次精读   | ~10 分钟                     | ~1 分钟                       |
| 准确率     | 视觉猜，受图碎片化拖累      | 用作者写的 caption，准确 > 90% |
| 图清晰度   | 依赖嵌入图像质量             | bbox 渲染原图，永远清晰        |
| 跨日 trend | 无                           | memory 提供上下文              |
