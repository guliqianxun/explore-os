# ft-004 Source: HF Papers

## 目标
抓取 HuggingFace Daily Papers（社区投票精选），作为第二个 `SourceFetcher` 实现，同时检验接口抽象。

## 设计
- 数据来源：`https://huggingface.co/api/daily_papers`（或页面解析，视可用性而定）
- 按日期窗口拉取，过滤 title/abstract 关键词命中（rewriter 产出的关键词列表）。
- 输出同样的 `Item`（`group=papers`，`source_key=hf_papers`），与 arXiv item 可统一渲染。
- HF Papers 的天然降噪属性 → 默认不做额外相关性截断，全量透传（上限 20/天）。

## 验收
- `manage.py fetch_source hf_papers --since 1d` 能返回当日精选列表。
- 和 arXiv item 可在同一分组渲染，不需要渲染器分支。
- 与 arXiv 重复的 paper（arxiv_id 相同）在去重阶段合并（由 ft-005 处理）。

## 风险
- HF 无正式 API 文档，端点稳定性待验证；做好 HTML 解析兜底。
