# ft-022 Electron 基础设施清理 + DRF API（重写）

> **2026-04-26 重写**：原 ft-022 packaging 调研已完成（rpt-002 / `docs/architecture/packaging.md`）。
> 本 ft 重新指代实施一阶段：把调研中识别的 9 个耦合点清理掉 + 把现有 CLI 包装为 DRF REST API，
> 为 ft-023 Electron shell + sidecar 铺路。

## 目标

让现有 Django 后端**作为 Electron 的 sidecar 可用**：
1. 消除 frozen exe 中 `BASE_DIR` 不可写的路径假设（耦合点 C1）
2. SMTP fallback：写 `.eml` 到下载目录而非依赖远程 SMTP（耦合点 C3）
3. 调度器 in-process（APScheduler，耦合点 C5）
4. docling 模型缓存目录可重定位（C9）
5. 现有 management commands（`extract_paper` / `interpret_paper` / `render_graph` / `run_subscription`）暴露为 DRF API endpoint

## Scope

### 1. EXPLORE_OS_DATA_DIR 统一数据目录

`config/settings.py` 引入：

```python
import os
from pathlib import Path

def _resolve_data_dir() -> Path:
    """Electron sidecar 跑时由壳传入；命令行跑时默认本地。
    跨平台：%APPDATA%/explore-os / ~/Library/Application Support/explore-os / ~/.config/explore-os"""
    if env_dir := os.environ.get("EXPLORE_OS_DATA_DIR"):
        return Path(env_dir)
    if os.name == "nt":
        return Path(os.environ["APPDATA"]) / "explore-os"
    if sys.platform == "darwin":
        return Path.home() / "Library" / "Application Support" / "explore-os"
    return Path.home() / ".config" / "explore-os"

DATA_DIR = _resolve_data_dir()
DATA_DIR.mkdir(parents=True, exist_ok=True)
MEDIA_ROOT = DATA_DIR / "media"
DATABASES["default"] = env.db("DATABASE_URL", default=f"sqlite:///{DATA_DIR / 'explore_os.sqlite3'}")
```

替换以下 hardcoded 路径（C1 清单）：
- `subscriptions/memory.py:22` — memory 文件路径
- `sources/pdf_fetcher.py:29` — PDF 缓存
- `apps/extract/extractors/docling_ext.py` — figures 输出
- `apps/extract/figure_extractor.py`（legacy） — 同上
- `interpret/figure_extractor.py`（legacy 重导出，已是 wrapper）
- 其他凡是用 `BASE_DIR / "media"` 的位置

引入 `apps/core/paths.py` 集中管理：
```python
def media_dir(*parts: str) -> Path: ...
def papers_dir() -> Path: ...
def figures_dir(arxiv_id: str) -> Path: ...
def render_dir(arxiv_id: str) -> Path: ...
def cache_dir() -> Path: ...   # docling 模型缓存（HF_HOME 重定向）
```

### 2. SMTP fallback（C3）

`delivery/adapters/email.py`：当 `EMAIL_HOST` 未配置时，写 `.eml` 到 `DATA_DIR / "outbox"`，不抛错。
桌面端用户可手动转发或直接用本地邮件客户端打开。

### 3. APScheduler in-process（C5）

`apps/core/scheduler.py`：
- `BackgroundScheduler` 单例
- 注册 jobs：`run_subscription`（cron 触发）+ `extract_paper`（按 paper queue 触发）
- Electron 启 sidecar 时自动起 scheduler
- 暴露 `/api/schedule/status` / `/api/schedule/trigger/<job>` 端点

### 4. docling 模型缓存重定位（C9）

`apps/extract/extractors/docling_ext.py` 模块级在 import 时设置：
```python
import os
from apps.core.paths import cache_dir
os.environ.setdefault("HF_HOME", str(cache_dir() / "huggingface"))
os.environ.setdefault("TRANSFORMERS_CACHE", str(cache_dir() / "huggingface" / "transformers"))
```

frozen exe 中模型不会重下到只读 `_MEIPASS`，而是用户数据目录。

### 5. DRF API 包装现有 CLI

`apps/api/` 新建 Django app：

```python
# apps/api/views.py
class ExtractPaperView(APIView):
    def post(self, request):
        arxiv_id = request.data["arxiv_id"]
        pdf_path = request.data.get("pdf_path") or default_pdf_path(arxiv_id)
        # 异步：放入 APScheduler 队列，立即返回 job_id
        job = enqueue_extract(arxiv_id, pdf_path)
        return Response({"job_id": job.id, "status": "queued"})

class PaperListView(APIView):
    """列出所有已抓取 paper（从 extract_sections distinct paper_arxiv_id）。"""

class PaperDetailView(APIView):
    """单篇精读视图所需数据：sections + figures + tables + claims + counter_signals。"""
```

URL 路由（`config/urls.py`）：
```
/api/papers/                       GET  论文列表
/api/papers/<arxiv_id>/            GET  单篇详情
/api/papers/<arxiv_id>/extract/    POST 触发抽取
/api/papers/<arxiv_id>/interpret/  POST 触发解读
/api/papers/<arxiv_id>/render/     POST 触发渲染
/api/subscriptions/                GET/POST 订阅配置 CRUD
/api/run/                          POST 立即跑订阅
/api/jobs/<job_id>/                GET  job 状态
/api/health/                       GET  sidecar 健康检查（Electron 启动用）
```

## 风险

- 路径替换涉及多文件，可能漏：用 `git grep "BASE_DIR.*media"` 完整扫一遍
- Django settings DATABASES 切换 SQLite 时间已验证（rpt-003）：零 patch
- APScheduler 与 Django ORM 交互注意 thread safety：用 `BackgroundScheduler`（不是 `BlockingScheduler`），任务函数内部用 `transaction.atomic()`
- docling HF_HOME 重定向必须在 import docling 之前设置：放在 `apps/core/paths.py` import 顶部触发
