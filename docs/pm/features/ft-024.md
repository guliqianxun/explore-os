## 4 页设计

### 1. PaperListPage（论文列表）

- 顶部 toolbar：抓取触发按钮 / 订阅 dropdown / 日期 picker
- 列表：每行一篇 paper，PaperCard 卡片
  - 缩略主图（封面 figure 第一张）
  - 标题 + 作者 + 日期
  - claim 数 / counter_signal 数 badge
  - 状态：extracted / interpreted / rendered（三色 dot）
- 点击进入 PaperDetailPage

### 2. PaperDetailPage（精读视图，**最重要**）

布局：3 栏

```
┌────────────────────┬───────────────────────────┬──────────────────┐
│  目录 (左 250px)   │     Markdown 正文 (中)    │  解读面板 (右)   │
│  Sections          │  - rehype-katex 渲染公式  │  - Claim 卡片列  │
│  - Abstract        │  - figures 内嵌           │  - Counter signal│
│  - 1. Intro        │  - tables 滚动            │    Badges        │
│  - 3. Method       │  - cites hover popup      │  - 图谱 tab：    │
│  - ...             │                           │    Excalidraw    │
│                    │                           │    嵌入          │
└────────────────────┴───────────────────────────┴──────────────────┘
```

- **左栏**：sections 树，level=1 为主，level=2 缩进
- **中栏**：从 `/api/papers/<id>/markdown` 拿 Docling markdown，react-markdown 渲染
  - figure 节点：`<img>` 指向 `/api/papers/<id>/figure/<seq>.png`
  - formula：`$$...$$` → katex
  - cites：`[fig:N]` 等 anchor 跳转
- **右栏（核心）**：
  - Tab 1 「Claims」：ClaimList 组件，每条 claim 卡片显示 text + cite badges + counter_signal 红色批注
  - Tab 2 「Graph」：GraphEmbed 组件加载 `/api/papers/<id>/graph.excalidraw` 的 JSON，传给 `<Excalidraw initialData={...} />`
  - 点击右栏 claim 卡 → 中栏 markdown 滚动到对应 evidence material
  - 点击右栏 graph 节点 → 选中对应 claim 卡 + 滚动 markdown

### 3. SubscriptionPage（订阅配置）

- 列表所有订阅（从 `/api/subscriptions/`）
- 每条订阅显示：interests / sources / delivery / schedule
- 编辑模态框：YAML editor（Monaco editor 或简化 textarea + JSON validator）
- 新建按钮 + 删除（确认对话框）

### 4. RunPage（抓取触发）

- 大按钮「立即抓取今日」→ POST `/api/run/`
- 进度条 + log 流（SSE 或轮询 `/api/jobs/<id>/`）
- 历史 run 列表（最近 20 次）

## API client 约定

```typescript
// frontend/src/api/client.ts
import axios from "axios";
const port = (window as any).explore?.getBackendPort?.() ?? 8000;
export const api = axios.create({
  baseURL: `http://127.0.0.1:${port}/api`,
  timeout: 30_000,
});
```

## Excalidraw 嵌入要点

```tsx
import { Excalidraw } from "@excalidraw/excalidraw";
import "@excalidraw/excalidraw/index.css";

export function GraphEmbed({ arxivId }: { arxivId: string }) {
  const { data } = useQuery({
    queryKey: ["graph", arxivId],
    queryFn: () => api.get(`/papers/${arxivId}/graph.excalidraw`).then(r => r.data),
  });
  if (!data) return <Skeleton />;
  return (
    <div className="h-full w-full">
      <Excalidraw initialData={data} viewModeEnabled={false} />
    </div>
  );
}
```

`viewModeEnabled={false}` 允许用户编辑（拖动节点、加批注）；保存到本地由 Excalidraw 自身处理（Browser localStorage）。后期可加「保存编辑后的图谱回 server」按钮。

## DRF API 增量（ft-022 已建立框架，本 ft 加端点）

```
/api/papers/<arxiv_id>/markdown/         GET   返回 docling markdown 文本
/api/papers/<arxiv_id>/figure/<seq>.png  GET   返回图片二进制
/api/papers/<arxiv_id>/graph.excalidraw  GET   返回 .excalidraw JSON
/api/papers/<arxiv_id>/claims/           GET   返回 claims + evidence + counter_signals 完整 JSON
/api/jobs/                               GET   list jobs
/api/jobs/<job_id>/stream                GET   SSE 实时 log（可选）
```

> 这些 endpoint 是 ft-022 的扩展，可在 ft-022 实施过程中一并落地，避免 ft-024 时重新打开 Python 改动。

## 风险

- **PaperDetailPage 三栏联动**：scroll-to-evidence + graph→claim 选中 双向同步是细节工作量黑洞，先做单向（claim → markdown），双向留 v1.x
- **Excalidraw 嵌入版本兼容**：@excalidraw/excalidraw 与 React 19 可能有 peer 冲突；锁定 React 18 LTS
- **Tailwind 4 vs 3**：用 Tailwind 3（更稳）
- **shadcn/ui 不是 npm 包**：是 cp 到本地的代码，要 commit 到仓库
- **Markdown 渲染数学公式**：rehype-katex 要在 vite.config 中正确配置
