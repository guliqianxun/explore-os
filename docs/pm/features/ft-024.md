# ft-024 前端 MVP 4 页

## 目标

把 explore-os 从「CLI + 文件交付」升级为**桌面应用日用形态**。
4 页 MVP 覆盖核心日用动作：发现 → 阅读 → 配置 → 触发。

## 4 页设计

### 1. PaperListPage（论文列表）

- 顶部 toolbar：抓取触发按钮 / 订阅 dropdown / 日期 picker
- 列表：每行一篇 paper，PaperCard 卡片
  - 缩略主图（封面 figure 第一张）
  - 标题 + 作者 + 日期
  - claim 数 / counter_signal 数 badge
  - 状态：extracted / interpreted / rendered（三色 dot）
- 点击进入 PaperDetailPage

### 2. PaperDetailPage（精读视图，**最重要**）

布局：3 栏

```
┌────────────────────┬───────────────────────────┬──────────────────┐
│  目录 (左 250px)   │     Markdown 正文 (中)    │  解读面板 (右)   │
│  Sections          │  - rehype-katex 渲染公式  │  Claim 卡片列     │
│  - Abstract        │  - figures 内嵌           │  - text          │
│  - 1. Intro        │  - tables 滚动            │  - cite badges   │
│  - 3. Method       │  - cites hover popup      │  - counter_signal│
│  - ...             │                           │  - equation 嵌入  │
│                    │                           │    (KaTeX 渲染)   │
└────────────────────┴───────────────────────────┴──────────────────┘
```

- **左栏**：sections 树，level=1 为主，level=2 缩进
- **中栏**：从 `/api/papers/<id>/markdown` 拿 Docling markdown，react-markdown 渲染
  - figure 节点：`<img>` 指向 `/api/papers/<id>/figure/<seq>.png`
  - formula：`$$...$$` → katex
  - cites：`[fig:N]` 等 anchor 跳转
- **右栏（核心）**：纯 React + KaTeX，**不嵌 Excalidraw**
  - ClaimCard 组件：每条 claim 显示 text + cite badges + counter_signal 红条 + equation 嵌入（KaTeX `<BlockMath>` 真渲染，不再用静态 PNG）
  - 点击右栏 claim 卡 → 中栏 markdown 滚动到对应 evidence material
  - claim 之间的关系靠 cite badges 跳转 + 视觉缩进，不画图谱

> **图谱可视化推迟到 v1.x**（2026-04-26 决策）：v0.8 ft-021 cluster cards 实测可读性不及 HTML，Excalidraw 静态格式无折叠 / 无交叉跳转 / 无 KaTeX live 渲染。HTML+React 自然支持这些，且 v1.0 Electron 壳里嵌图谱 viewer 是 v1.x 的工作。

### 3. SubscriptionPage（订阅配置）

- 列表所有订阅（从 `/api/subscriptions/`）
- 每条订阅显示：interests / sources / delivery / schedule
- 编辑模态框：YAML editor（Monaco editor 或简化 textarea + JSON validator）
- 新建按钮 + 删除（确认对话框）

### 4. RunPage（抓取触发）

- 大按钮「立即抓取今日」→ POST `/api/run/`
- 进度条 + log 流（SSE 或轮询 `/api/jobs/<id>/`）
- 历史 run 列表（最近 20 次）

## ClaimCard React 组件要点（**取代原 Excalidraw 嵌入设计**）

```tsx
import { BlockMath, InlineMath } from "react-katex";
import "katex/dist/katex.min.css";

interface Claim {
  claim_id: string;
  text: string;
  claim_type: "proposal" | "result" | "ablation" | "theoretical";
  confidence: number;
  evidences: Array<{ kind: string; ref_id: string; label: string; image_path?: string }>;
  equation_evidences: Array<{ ref_id: string; label: string }>;  // label = LaTeX 源码
  counter_signals: Array<{ text: string; signal_type: string; evidence_ref_id: string }>;
}

export function ClaimCard({ claim, onCiteClick }: { claim: Claim; onCiteClick: (refId: string) => void }) {
  return (
    <div className="rounded-lg border border-blue-300 bg-blue-50/50 p-4 space-y-3">
      <div className="flex items-center gap-2 text-xs">
        <Badge variant={badgeVariant(claim.claim_type)}>{claim.claim_type}</Badge>
        <span className="text-muted-foreground">conf {claim.confidence.toFixed(2)}</span>
      </div>
      <p className="text-sm leading-relaxed">{claim.text}</p>
      {/* equation 真渲染 */}
      {claim.equation_evidences.map(eq => (
        <div key={eq.ref_id} className="bg-white rounded p-2 overflow-x-auto">
          <BlockMath math={eq.label} errorColor="#cc0000" />
        </div>
      ))}
      {/* cite badges */}
      <div className="flex flex-wrap gap-1">
        {claim.evidences.map(ev => (
          <button onClick={() => onCiteClick(ev.ref_id)} className="text-xs ...">
            {ev.kind === "figure" ? "📊" : "📋"} {ev.ref_id}
          </button>
        ))}
      </div>
      {/* counter_signal 红条 */}
      {claim.counter_signals.map((cs, i) => (
        <div key={i} className="border-l-4 border-red-400 bg-red-50 p-2 text-xs">
          <span className="font-semibold text-red-700">⚠ {cs.signal_type}</span> {cs.text}
        </div>
      ))}
    </div>
  );
}
```

**前端栈追加 KaTeX**：`react-katex` + `katex` 两个包（Excalidraw 包从 ft-024 依赖中移除）。
import "@excalidraw/excalidraw/index.css";

export function GraphEmbed({ arxivId }: { arxivId: string }) {
  const { data } = useQuery({
    queryKey: ["graph", arxivId],
    queryFn: () => api.get(`/papers/${arxivId}/graph.excalidraw`).then(r => r.data),
  });
  if (!data) return <Skeleton />;
  return (
    <div className="h-full w-full">
      <Excalidraw initialData={data} viewModeEnabled={false} />
    </div>
  );
}
```

`viewModeEnabled={false}` 允许用户编辑（拖动节点、加批注）；保存到本地由 Excalidraw 自身处理（Browser localStorage）。后期可加「保存编辑后的图谱回 server」按钮。

```
