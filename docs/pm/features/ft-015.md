# ft-015 学术 PDF 解析升级（Docling）

## 触发条件（已击穿）

实战 LeWorldModel.pdf：
- 启发式 figure 配对率 **~9/19**（矢量图全军覆没——`pymupdf get_images()` 拿不到 SVG/mxgraph）
- equations: **0**（启发式正则无召回）
- citations: 75 启发式条 **title 大多空**
- sections: 8（仅靠 markdown `**...**` 模式）

**启发式天花板已踩穿**，启动 Docling 替换。

## 实测结论（probe 已完成）

`scripts/probe_docling.py` + RTX 4090 + GPU + `do_formula_enrichment=True` + `generate_picture_images=True` 跑同一篇 LeWorldModel.pdf：

| 指标 | 启发式 | Docling | 提升 |
|---|---|---|---|
| Sections | 8 | 33 | 4× |
| Pictures with image+caption | 9/19 | **19/19** | 配对率 100% |
| Tables (含 markdown 行) | 9 (caption only) | 9 (caption + 行内容) | 内容化 |
| Equations as LaTeX | 0 | **31** | ∞ |
| Citations (清洁度) | title 大多空 | **57**（每条完整作者+标题+venue+年份） | 大幅 |
| 总耗时 | ~5s | 482s（含模型加载） | 可接受 |

## 选型决策

**Docling**（IBM，MIT 许可）。
理由：
- 把图、表、公式、章节、caption、references **打了干净的 label**，本质消除写正则的需求
- MIT 许可清洁，未来桌面 app 分发无授权风险
- 矢量图原生 render（PDF 区域 → PNG），解决启发式最大痛点
- 公式输出 LaTeX，可直接 katex/mathjax 渲染
- Python 包 + 模型权重经 HuggingFace 自动下载，无需外部 docker

**已弃**：pdffigures2（Java + docker，包体复杂）/ Nougat（CC-BY-NC 商用受限 + 不导出图）。

## 关键设计决策

1. **模型加载**：DoclingExtractor 用模块级单例缓存 `DocumentConverter`，首次调用 ~30s 加载，后续 paper ~30–60s
2. **GPU 自动检测**：`torch.cuda.is_available()` 决定 `AcceleratorDevice.CUDA` 还是 `CPU`
3. **公式映射**：docling `text.label == "formula"` → `EquationMaterial`，`latex_or_text` 存 LaTeX 字符串，`inline_or_display = "display"`
4. **Citation 映射**：扫到 `section_header` 文本含 "reference"（不区分大小写）后，连续 `list_item` 都作为 `CitationMaterial`，`raw_text` 存原文，`bibkey/year/title` 用最简启发式抽（抽不到留空）
5. **Section 映射**：每个 `section_header` 一条 `SectionMaterial`，`path` 用 header text，`level` 从 docling `level` 字段（无则 1），`raw_text` 暂存空（v0.7 解读器不需要全文 raw_text，需要时再补）
6. **Figure 映射**：每个 `pictures[i]` → `FigureMaterial`，`image_path = media/figures/<arxiv_id>/<material_id>.png`，`fig_label` 从 caption 文本抽 "Figure N"，`bbox` 存 docling prov.bbox（`[x0,y0,x1,y1]`）
7. **Table 映射**：每个 `tables[i]` → `TableMaterial`，`raw_text = table.export_to_markdown()`，`caption + bbox + tbl_label` 同 figure

## 性能 / 成本约束

- 单篇 ~30–60s（GPU warm）/ ~5–8 min（CPU 首次）—— 桌面端可接受
- 模型权重总量 ~600MB（layout heron + CodeFormulaV2 + RapidOCR），缓存到 HuggingFace 默认目录
  - **桌面 app 形态时**（v1.0）改到 `EXPLORE_OS_DATA_DIR`，已记入 ft-022 耦合点清单
- 不调外部 LLM API，零 token 成本
