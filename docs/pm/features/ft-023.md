# ft-023 Electron shell + Python sidecar

## 目标

让 explore-os 作为 **本地 desktop app 启动**：
1. Electron 壳启动 BrowserWindow
2. fork Python sidecar（PyInstaller 打包的 Django + Daphne/Waitress）
3. 通过 HTTP localhost 通信
4. 关窗时优雅杀 sidecar

**本 ft 不含前端 UI**（一个空 BrowserWindow 加载 about:blank 或简陋 dev page 即可）。前端 MVP 留 ft-024。

## 三个核心模块

### 1. main.ts（Electron 主进程）

```typescript
import { app, BrowserWindow } from "electron";
import { startSidecar, stopSidecar } from "./sidecar";

let mainWindow: BrowserWindow | null = null;
let sidecarPort: number | null = null;

app.whenReady().then(async () => {
  sidecarPort = await startSidecar();
  mainWindow = new BrowserWindow({
    width: 1280, height: 800,
    webPreferences: {
      preload: path.join(__dirname, "preload.js"),
      contextIsolation: true,
      nodeIntegration: false,
    },
  });
  // dev: 加载 vite dev server；prod: 加载 file:// 静态资源（ft-024 之后）
  if (process.env.VITE_DEV_SERVER_URL) {
    mainWindow.loadURL(process.env.VITE_DEV_SERVER_URL);
  } else {
    mainWindow.loadFile(path.join(__dirname, "../frontend/dist/index.html"));
  }
});

app.on("window-all-closed", () => {
  stopSidecar();
  if (process.platform !== "darwin") app.quit();
});

app.on("before-quit", stopSidecar);
```

### 2. sidecar.ts（Python 进程管理）

```typescript
import { spawn, ChildProcess } from "child_process";
import { findFreePort } from "./port";

let sidecarProc: ChildProcess | null = null;

export async function startSidecar(): Promise<number> {
  const port = await findFreePort(8000, 8999);
  const dataDir = getUserDataDir();   // app.getPath("userData")
  const exePath = getSidecarExe();    // resolves PyInstaller bundle path
  sidecarProc = spawn(exePath, ["--port", String(port), "--data-dir", dataDir], {
    env: { ...process.env, EXPLORE_OS_DATA_DIR: dataDir, PYTHONUNBUFFERED: "1" },
    stdio: ["ignore", "pipe", "pipe"],
  });
  sidecarProc.stdout?.on("data", (b) => console.log("[sidecar]", b.toString().trim()));
  sidecarProc.stderr?.on("data", (b) => console.error("[sidecar]", b.toString().trim()));
  // 健康检查：轮询 http://127.0.0.1:<port>/api/health 直到 200
  await waitForHealth(port);
  return port;
}

export function stopSidecar() {
  if (sidecarProc && !sidecarProc.killed) {
    sidecarProc.kill();   // SIGTERM；Windows 用 taskkill /T 兜底
    sidecarProc = null;
  }
}
```

进程清理边界：
- macOS / Linux：SIGTERM → SIGKILL（5s timeout）
- Windows：`taskkill /F /T /PID <pid>` 兜底（child_process 不会杀 grandchildren）
- watchdog：sidecar 启动时拿 ELECTRON_PID env，子进程定时检查父 PID 是否存在，不在则 self-terminate

## PyInstaller Django 打包

`build/sidecar.spec`（PyInstaller spec）：

```python
# -*- mode: python -*-
import sys
from pathlib import Path

block_cipher = None

a = Analysis(
    ["sidecar_entry.py"],   # 新增的 sidecar 入口（见下）
    pathex=[str(Path.cwd())],
    binaries=[],
    datas=[
        ("config", "config"),
        ("apps", "apps"),
        ("interpret", "interpret"),
        ("delivery", "delivery"),
        ("sources", "sources"),
        ("subscriptions", "subscriptions"),
    ],
    hiddenimports=[
        "django.template.loaders.app_directories",
        "rest_framework",
        "apps.extract.apps", "apps.interpret.apps", "apps.render.apps",
        "apps.core.apps", "apps.api.apps",
        # docling / torch 隐式 import 收集
        "docling", "docling.document_converter",
    ],
    hookspath=["build/hooks"],
    runtime_hooks=[],
    excludes=["pytest", "ruff"],
    win_no_prefer_redirects=False,
    win_private_assemblies=False,
    cipher=block_cipher,
    noarchive=False,
)

pyz = PYZ(a.pure, a.zipped_data, cipher=block_cipher)
exe = EXE(pyz, a.scripts, [], exclude_binaries=True,
          name="explore-os-sidecar", debug=False, bootloader_ignore_signals=False,
          strip=False, upx=False, console=True)
coll = COLLECT(exe, a.binaries, a.zipfiles, a.datas, strip=False, upx=False,
               name="explore-os-sidecar")
```

`sidecar_entry.py`（新增）：
```python
"""PyInstaller entry: starts Django via Waitress on given port."""
import argparse
import os
import sys

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--port", type=int, required=True)
    parser.add_argument("--data-dir", required=True)
    args = parser.parse_args()
    os.environ["EXPLORE_OS_DATA_DIR"] = args.data_dir
    os.environ.setdefault("DJANGO_SETTINGS_MODULE", "config.settings")
    import django
    django.setup()
    # migrate（首次启动）
    from django.core.management import call_command
    call_command("migrate", "--noinput")
    # 启动 waitress
    from waitress import serve
    from config.wsgi import application
    print(f"[sidecar] listening on 127.0.0.1:{args.port}", flush=True)
    serve(application, host="127.0.0.1", port=args.port)

if __name__ == "__main__":
    main()
```

## CUDA / CPU 双轨（v1.2 ft-025 落实，本 ft 先支持 CUDA）

`build/sidecar-cuda.spec` / `build/sidecar-cpu.spec` 两个 PyInstaller spec：
- CUDA 版（自用，~1.5GB）：包 cu124 torch + nvidia DLL
- CPU 版（分发接口）：包 CPU torch（pyproject.toml `[tool.uv.sources]` 切 index）

本 ft 先做 CUDA 版打包跑通；CPU 版 spec 留 stub 注释，由 ft-025 实施。

## 验收

1. `npm run dev:electron` 启动 Electron 窗口 + Python sidecar，前端 about:blank
2. 浏览器开发者工具 → `fetch("/api/health")` 返回 200
3. 关窗后 `tasklist | findstr explore-os-sidecar`（Windows）/ `pgrep` 无残留
4. `npm run build:all` 在 Windows 产出 NSIS 安装包，安装后能启动并跑 sidecar（自用机器实测）
5. 安装包大小 < 2GB（CUDA 版预期 ~1.5GB）
6. **不破现有 Django CLI**：`uv run python manage.py extract_paper ...` 仍能跑

## 风险

- **PyInstaller × CUDA torch hidden imports**：torch 动态加载 CUDA DLL 经常被漏；hooks 目录预置 `hook-torch.py` 显式 collect
- **docling 模型路径**：HF_HOME 在 frozen exe 中要走 `_MEIPASS` 之外的目录（已在 ft-022 通过 `cache_dir()` 处理）
- **Windows 子进程清理**：`taskkill /F /T /PID` 兜底，避免 grandchildren 残留
- **macOS sidecar 权限**：Apple Sandbox 对 spawn 子进程有限制；自用阶段不上 sandbox
