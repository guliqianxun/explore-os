# ft-017 飞书 DeliveryAdapter

## 目标
让订阅可以通过飞书自定义机器人 webhook 推送日报。
适合"团队群" / "个人飞书私聊机器人" 等场景。

## 实施方案选型

### A. 自定义机器人 Webhook（推荐 MVP）
- 群里加自定义机器人，拿到 webhook URL
- 直接 POST JSON 到 URL，不需要 app_id / app_secret
- 限制：消息只能发到这个群；卡片元素受限（不直接支持本地图，要先上传换 image_key）

### B. 应用机器人 + tenant_access_token
- 注册飞书开放平台应用 → 拿 app_id / app_secret
- 调 `tenant_access_token` 接口（每 ~2h 刷新）
- 用 `im/v1/messages` 发到指定 chat_id / open_id / user_id
- 优势：能发到任何群、任何用户、能私聊
- 代价：注册 + 配置复杂

MVP 走 A。

## 卡片设计

飞书富文本卡片（[card 文档](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/feishu-cards/quick-start/getting-started)）：

```
+--------------------------------------------+
|  📰 [explore-os] {sub.name} · {date}        |  header
+--------------------------------------------+
|  [今日主题速览] hero_sentence              |  callout
|  - bullet 1                                |
|  - bullet 2                                |
+--------------------------------------------+
|  ★ 精读 (N)                                 |
|  ┌──────────────────────────────────────┐  |
|  │ #1 标题                                │  |
|  │ image (framework)                     │  |
|  │ 中文摘要                               │  |
|  │ 方法 / 创新 / 局限 / 视角解读         │  |
|  │ [按钮: 查看原文]                       │  |
|  └──────────────────────────────────────┘  |
|  ...                                       |
+--------------------------------------------+
|  略读 (M)                                  |
|  - #2 标题 · 一句话摘要 · [link]            |
|  ...                                       |
+--------------------------------------------+
```

## 实现要点

1. 图上传：POST `https://open.feishu.cn/open-apis/im/v1/images`
   - 自定义机器人 webhook 不能调此 API（需要 token）→ MVP 用 image_url（图先 host 到能公开访问的地方）或退化为不显示图
   - 完整方案需要 B（应用机器人）

2. Webhook payload 结构：
   ```json
   {
     "msg_type": "interactive",
     "card": { "header": {...}, "elements": [...] }
   }
   ```

3. 长内容拆分：飞书卡片单条上限约 30K 字符，超长拆多卡

## target.params 字段
```yaml
deliveries:
  - channel: feishu
    params:
      webhook: "https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxx"
      # 或（应用机器人模式）：
      # app_id: cli_xxx
      # app_secret: xxx
      # receive_id: oc_xxx (chat_id) 或 ou_xxx (open_id)
      # receive_id_type: chat_id | open_id
```
