# ft-028 Paper-centric schema + user_* 层 + Inbox verdict

## 战略上下文（必读）

CLAUDE.md 原定位"订阅驱动的信息检索推送助手"在 ft-022~ft-027 一路扩展为
"桌面阅读站"。4/28 用户拍板把产品形态显式锁定为：

- **A 入口**：Subscription brief + Ingest（已有）
- **B 沉淀**：每篇论文挂 status / comment(history) / tag / paper-level 双链（**本 ft 起**）
- **能力切片**：内嵌 pdf.js 做"对照型"PDF 浏览；导出到 Zotero / 在 readest
  打开是逃生口（不重造轮子）— 这两块在 ft-029/030

本 ft 是地基：上 user_* 层之前必须先把 Paper 实体抽出来。

## 决策（已 lock 2026-04-28）

| # | 决策 | 备注 |
|---|---|---|
| 1 | Paper-centric schema **彻底重构** | 不走"先用 arxiv_id 当 key"短期方案 |
| 2 | Paper.stable_key = `[A-Z2-9]{8}` | Zotero 风格 8-char，title 显示 |
| 3 | arxiv_id / doi 降为 Paper 可选元数据列 | 不再是任何表的 PK |
| 4 | 5 类 material + 解释层 FK 全部改指 `Paper.id` | 一次性数据迁移 |
| 5 | API path 同时接受 `<key>` 和 `<arxiv_id>` | 不破 frontend 现有 URL |
| 6 | user_* 4 张表：status / comment / tag / backlink | 单用户 Electron 场景 |
| 7 | 状态机 5 态：`new → queued → reading → read_kept / read_dropped → archived` | snoozed 并入 queued |
| 8 | comment **append-only**（不可改不可删，仅可标 hidden）| 留 history |
| 9 | backlink 只 `paper ↔ paper`，**claim 级延后** | 先验证 paper 级有用 |
| 10 | brief 不压抑已决；arxiv v1/v2 **不合并**（不同 Paper 实体）| 用户后续手动建 backlink |

## 风险

- **stable_key 唯一性 + 重试**：8-char Base32 (A-Z2-9) 空间 32^8 ≈ 1e12，
  per-paper 个体冲突概率 ~0；但 `gen_key()` 仍要 try 3 次再让 IntegrityError
  冒泡
- **数据迁移 forward-only 风险**：必须每步可 reverse；本地先在 SQLite copy
  上验证完整 forward → reverse 一遍
- **API path 双 id 解析**：regex 必须严格（避免 arxiv_id 形如 `2401.A2C3D4E5`
  匹配 key 正则）。arxiv_id 实际是 `\d{4}\.\d{4,5}` 或 `\w+\-\w+/\d+`，
  跟 `[A-Z2-9]{8}` 不重合
- **frontend status filter UX**：默认 `new` 后用户首次会"什么都看不到"
  因为既有所有 paper 默认 status=new — 这个其实就是想要的"今日 brief"行为；
  但是要在空状态写明 "0 unread papers, view all →"
- **既有 sources / interpret_v2 / render_* 表是否也要 FK 重接**：派发前
  Subagent 必须先 `grep -r paper_arxiv_id apps/` 完整列出受影响表

### URL 解析

```python
# apps/api/views.py
PAPER_KEY_RE = re.compile(r"^[A-Z2-9]{8}$")

def resolve_paper(id_or_key: str) -> Paper:
    if PAPER_KEY_RE.match(id_or_key):
        return Paper.objects.get(key=id_or_key)
    return Paper.objects.get(arxiv_id=id_or_key)
```
