# ft-029 Reading Station：3 栏 + pdf.js 内嵌 + notes 编辑

## 战略上下文

ft-028 落地了 Paper 顶层实体 + status / comment / tag / backlink schema 和
Inbox 入口 verdict UI。本 ft 上层建：把"打开一篇 paper 深读"的体验做出来。

按 4/28 锁定的能力切片：

- **explore-os 内嵌 pdf.js 做"对照型"viewer**（不做标注 / 不做沉浸阅读）
- 标注层全部去 user_comment / user_tag / user_backlink，**挂在 claim/section
  /figure 这些已解释对象上**
- "想沉浸式读" → 一键导出 / 在 readest 打开（ft-030）

### Backend（小，~1 天）

#### 1. Paper.pdf_path 字段 + 自动填充

```python
# apps/papers/models.py 加
class Paper(models.Model):
    ...
    pdf_path = models.TextField(null=True, blank=True)  # 绝对路径
```

迁移：`apps/papers/migrations/0010_paper_pdf_path.py`（NOT NULL=False，不需要数据迁移）

ingest 链 (`apps/api/ingest.py`) 落盘成功后写 `paper.pdf_path = str(papers_dir() / fname)`。

兼容回退：当 `pdf_path` 为空，按旧规则探测：

```python
def resolve_pdf_path(paper: Paper) -> Path | None:
    if paper.pdf_path and Path(paper.pdf_path).exists():
        return Path(paper.pdf_path)
    if paper.arxiv_id:
        for d in (papers_dir(), pdf_legacy_dir()):
            p = d / f"{paper.arxiv_id}.pdf"
            if p.exists():
                return p
    return None
```

#### 2. PDF serve endpoint

```
GET /api/papers/<id>/pdf/
```

实现：

```python
class PaperPdfView(APIView):
    def get(self, request, id_or_key: str):
        paper = resolve_paper(id_or_key)
        path = resolve_pdf_path(paper)
        if path is None:
            return Response({"detail": "pdf not available"}, status=404)
        return FileResponse(open(path, "rb"), content_type="application/pdf")
```

**Range request 支持**：DRF `FileResponse` 默认不开 Range — pdf.js 部分加载需要。考虑：

- 简单方案：返回完整 PDF body（Content-Length 设好），pdf.js 自动 fall back 全量下载。论文 PDF 一般 1-10MB，全量可接受。
- 高级方案：手写 Range parser（HTTP 206 Partial Content）— **本 ft 不做**，留 ft-030 优化时再说。

测试：tests_papers.py 加 2 例（happy + 404）。

#### `PdfViewer`（新，核心）

```tsx
interface PdfViewerProps {
  pdfUrl: string;
}
interface PdfViewerHandle {
  scrollToPage(page: number): void;
  highlightBox(page: number, bbox: [number, number, number, number]): void;
  searchText(query: string): void;
}
export const PdfViewer = forwardRef<PdfViewerHandle, PdfViewerProps>(...);
```

实现要点：

- `<Document file={pdfUrl}>` 包 `<Page pageNumber=... renderTextLayer />`
  按虚拟滚动渲染（每页约 50KB 页面 DOM，~30 页论文渲染 ~1.5MB DOM 可接受）
- `highlightBox`：在指定 Page 上叠 absolute div，2s 后渐隐。bbox px 坐标
  按 page 渲染 scale 转换：`scale = renderedWidth / nativeWidth`
- `searchText`：调 pdf.js `findController.executeCommand("find", {query})`，
  结果 scroll 到首个高亮
- worker 路径：`pdfjs.GlobalWorkerOptions.workerSrc = ...`（vite 用
  `?url` import worker bundle）

#### 跨引（`onCiteClick` 联动）

```tsx
function handleCite(materialId: string) {
  // material_id 形如 "<arxiv>:fig:3" / ":sec:Introduction" / ":eq:5"
  const fig = detail.figures.find(f => f.material_id === materialId);
  if (fig) {
    pdfRef.current?.scrollToPage(fig.page);
    if (fig.bbox) pdfRef.current?.highlightBox(fig.page, fig.bbox as any);
    return;
  }
  const sec = detail.sections.find(s => s.material_id === materialId);
  if (sec) {
    pdfRef.current?.searchText(sec.path.slice(0, 60));
    return;
  }
  // tbl 同 fig；eq 不跳（已在卡上展示 LaTeX）
}
```

## 风险

1. **pdf.js bundle 体量**：pdfjs-dist 4 mainfile 600KB+ gzip。必须 dynamic
   import 让 vite split 出 chunk。主会话需 verify build 后主 chunk 大小
   不爆。`build.rollupOptions.output.manualChunks` 兜底切。
2. **worker 配置 cross-platform**：Electron file:// 协议下 pdf.js worker
   通常需 `import.meta.url + ?url` 拿绝对路径。frontend agent 试通即记。
3. **bbox 坐标转换**：docling bbox 是 PDF 坐标系（左下原点 in points）vs
   pdf.js render canvas（左上原点 in px）。需要：scale + Y 翻转。已知坑：
   PDF.js `viewport.convertToViewportPoint()` 可用。
4. **Range request**：本 ft 不做 Range，论文 < 10MB 全量下载可接受；用户
   实测如等待 > 5s 再说。
5. **resize panel 状态持久**：localStorage 存 size 数组，但要兼容用户拖到
   极小再切回。`react-resizable-panels` 自带 `autoSaveId` 即可。
6. **claim:section 跨引精度**：section.path 可能跟 PDF 里实际标题样式略有
   差（如 "1. Introduction" vs "1 Introduction"）。pdf.js 模糊查询不带就用
   开头 30 字 substring。
7. **pdf.js textLayer 与 bbox 高亮 z-index**：textLayer 默认 absolute，
   高亮 div 要 z-index > textLayer 但 < toolbar。
8. **react-pdf v9 vs Vite 5**：曾有 worker bundle 不正确路径问题。frontend
   agent 派发时**必须先做 hello-world 验证 pdf.js 能加载**再继续。
