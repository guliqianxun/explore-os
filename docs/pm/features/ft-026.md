# ft-026 前端编辑/杂志重设计

## 触发

ft-024 落地 4 页 MVP 实测后，UX 反馈：
- "工具感"压过"阅读感"，shadcn 默认像 SaaS 后台
- 三栏 IDE 布局对功能友好但反沉浸
- PaperList 像表，不像 feed
- ClaimCard 在右栏 400px 被压扁，公式 / counter_signal 看着局促

## 设计方向（已 lock，2026-04-27）

**Editorial / Magazine**：论文 = 一期杂志的封面文章。
- **品牌调性**：Distill × Stratechery 混合（严肃学术 × 温暖人文）
- **默认沉浸**：PaperDetail 单栏阅读，claims 折叠到右抽屉，按钮可展开
- **PaperList 是 feed**：日期分组 + hero（最值得读的）+ 每条 lead paragraph + 主图缩略
- **字体**：衬线正文（Source Serif 4 / 思源宋体 mix）+ 无衬线 UI（Inter / IBM Plex Sans）
- **色彩**：暖中性（light cream `#fdfcf8` / dark warm slate）+ accent 单色（深绿 / 焦糖橙待选）

## 范围

### 改造（保留架构，重做表现层）
- `PaperListPage`：网格 → editorial feed，按日期分组，第一条用 hero 卡片
- `PaperDetailPage`：默认单栏沉浸，右侧 claims 抽屉可滑入/隐藏，左侧 sections 改为浮动按钮触发的浮动目录
- `ClaimCard`：drawer 内独占 600px 宽，公式 / 长 text / counter_signal 红条全部宽松
- `PaperCard`：feed 形态（lead + 主图 + author 列表 + claim 数 hint）
- 整站新增 `ReadingMode` toggle（一键切到 immersive）

### 新增组件
- `frontend/src/components/HeroPaperCard.tsx`：feed 顶部大卡（含主图、长 lead）
- `frontend/src/components/ClaimDrawer.tsx`：右侧抽屉容器
- `frontend/src/components/FloatingTOC.tsx`：浮动目录按钮
- `frontend/src/components/ReadingModeToggle.tsx`：阅读模式切换

### 设计 token
- `frontend/src/styles/tokens.css`：
  - 字体栈（serif / sans / mono）
  - 色板（neutral warm scale + 单 accent）
  - 间距（呼吸感优先：行高 1.7+，paragraph 1.5em margin）
  - 阴影（极轻，editorial 不喜欢拟物）

### CORS 修复（顺手做）
跨 origin（5173 → 127.0.0.1:<port>）当前阻塞 API。两选一：
- (A) Electron `webPreferences.webSecurity: false`（单机 app 安全 OK）
- (B) Django 加 `django-cors-headers` + `CORS_ALLOW_ALL_ORIGINS=True`

**采用 B**（更通用，prod loadFile 也受影响，统一修）。

## 验收

1. PaperListPage：日期分组 feed + hero 卡片，单屏能看出"今天值得读什么"
2. PaperDetailPage：默认沉浸单栏，markdown 走衬线正文，公式真渲染，行高 1.7+
3. ClaimDrawer：右侧浮入，宽度 480-600px，公式 / 红条 / cite 不再局促
4. FloatingTOC：左下角按钮浮起目录，点击章节滚动
5. ReadingModeToggle：一键全屏 markdown
6. CORS 修复后，PaperListPage 实际能拉到 leworldmodel/convnextv2 数据
7. `npm run build` 0 error
8. 既有 Python 测试 ≥ 241

## 风险
- **字体加载**：需要 Source Serif 4 / 思源宋体 web font，bundle 会变大；可走 Google Fonts CDN（Electron 离线时退到 system serif）
- **抽屉性能**：PaperDetail 抽屉滑入需要平滑动画，Tailwind 现成够用
- **PaperCard hero 找主图**：从 `figures` 第一张拿（API 已支持）
