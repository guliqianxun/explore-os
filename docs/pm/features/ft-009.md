# ft-009 精读/略读分档渲染 + 视角注入

## 目标
把单一的 TL;DR 模板拆成「精读 + 略读」两档，并让所有解读以订阅声明的**视角**展开。

## 视角（perspective）

订阅 YAML 新增字段：
```yaml
perspective:
  preset: researcher   # researcher | engineer | pm | student | custom
  custom: "我是做视频生成模型研究的博士生，关注扩散/自回归/世界模型……"
```
- 填 `preset` 则用内置 system prompt 前缀
- 填 `custom` 则用自由文本作为 role 设定
- 两者都为空则走默认"中立第三方"

内置 preset：
- `researcher`：关注创新点、理论贡献、局限性
- `engineer`：关注能否落地、依赖、开源情况
- `pm`：关注产品化空间、用户价值、市场位置
- `student`：关注入门路径、是否适合复现

## 略读档（skim）

所有非 Top-N 入选篇。每篇 1 张小卡片：

```
[来源tag] 发布日期  标题（链接到原文）
作者 (截断)
>> 一句结构化要点（10-40 字，视角化）
#kw1 #kw2 #kw3
```

产出由 **LLM 结构化**一次性出（替换 ft-006 的 TL;DR）：
```json
{
  "one_liner": "...",
  "keywords": ["..."]
}
```
system prompt 包含视角前缀。

## 精读档（deep）

Top-N（ft-008 自适应，1–3 篇）入选。每篇完整块：

```
[精读 ★] 标题（链接）
作者 / 发布日期 / 来源 / 综合分

[原文摘要]   ← 原 abstract 字段原样返回，不做 LLM 改写
<abstract 原文>

[深度解读]   ← ft-011/012 产出的长版结构化解读；iter-002 暂时留空提示
(iter-003 将填充：方法 / 关键创新 / 实验亮点 / 局限 / 个人视角)

[框架图]    ← iter-003 ft-012 填充
(iter-003 将填充)

[标签] #kw1 #kw2 ...
```

注意：**不重复放 one_liner**（精读和略读职责分开）。

## 邮件模板结构

```
======================================================
[explore-os] <订阅名> · <日期>
[Daily Narrative]   ← ft-010 产出，2-3 句跨篇主题总览
======================================================

=== 精读 ★ (N items) ===
（按综合分降序）
<deep block 1>
<deep block 2>
...

=== 略读 (M items) ===
（按综合分降序）
<skim card 1>
...
```

## 文件范围
- `interpret/interpretation.py`（重命名 `tldr.py` 或在旁新增）：按 `tier` 调不同 prompt
  - `skim_interpret(item, perspective) -> SkimOut`
  - `deep_interpret(item, perspective) -> DeepOut`（iter-002 仅输出原文 abstract + 占位，iter-003 填内容）
- `delivery/email_renderer.py`：支持 deep / skim 分区
- `subscriptions/loader.py`：加 `perspective` 字段解析
- `subscriptions/management/commands/run_subscription.py`：替换 TL;DR 步骤为分档解读
- 兼容：`ft-006 tldr.py` 保留为兼容别名，新代码走 interpretation.py

## 测试
- `tests_interpretation.py`：mock LLM，验证 skim / deep 输出结构、视角 prompt 注入
- `tests_email_renderer.py`（新增）：验证分档渲染、HTML 结构、空档位兜底

## 验收
- 订阅加 `perspective.preset=researcher` 后，解读措辞能看出视角差异（人工验）
- 邮件里精读和略读视觉区分明显（icon / 颜色块）
- 精读档没有 one_liner；略读档只有一句
- 精读 abstract 展示为原文（不是改写）
