# ft-027 Subscription 表单化 + RunPage → Ingest

## 触发

ft-026 编辑/杂志重设计实测后用户反馈：
- ✅ PaperList 形态满意，留
- ⚠️ SubscriptionPage 仍是 yaml textarea —— 开发者视角，不是用户视角
- ⚠️ RunPage 定位不清 —— "Trigger subscription" 跟 cron 重复，没价值

## 决策（已 lock 2026-04-27）

1. **存储不动**：subscriptions 仍走 YAML 文件（backend `subscriptions/loader.py` 不改）
2. **三种 ingest 都支持**：PDF 拖入 + arxiv id + URL
3. **Trigger 移到 SubscriptionCard**：每个订阅卡上有 [▶ Run now] 按钮；RunPage 专做 ingest

## 范围

### Backend（apps/api/）

**新增 endpoints**：
```
GET    /api/subscriptions/              列表（从 YAML 读）
POST   /api/subscriptions/              创建（写 YAML）
PUT    /api/subscriptions/<name>/       更新（写 YAML，按 name 做 key）
DELETE /api/subscriptions/<name>/       删除
POST   /api/subscriptions/<name>/run/   立即跑这一条订阅（异步 job）

POST   /api/ingest/upload/              multipart PDF 上传 → 链 extract+interpret+render
POST   /api/ingest/arxiv/               JSON {arxiv_id} → fetch + 链
POST   /api/ingest/url/                 JSON {url} → fetch + 链
```

复用：
- `subscriptions/loader.py`（YAML 读写）
- `sources/pdf_fetcher.py`（按 arxiv_id 拉 PDF）
- `apps/api/jobs.py`（job queue + chain）
- `apps/core/paths.py::papers_dir()`（PDF 落盘）

新增 `apps/api/ingest.py` 模块：链式调度 extract → interpret → render，三阶段都成功才算完成，任一失败保留 job error。

## 验收

1. SubscriptionPage 是卡片列表 + 表单 modal，YAML editor 折叠到 Advanced
2. 每张 SubscriptionCard 有 [▶ Run now] 触发对应订阅，job_id 返回 + 进度可看
3. IngestPage 三种 input 都能跑通：
   - 拖入 PDF → 自动 ingest 链
   - 输入 arxiv id `2401.12345` → 拉 PDF → ingest 链
   - 输入 URL → 下载 → ingest 链
4. In progress 列表实时显示三阶段状态，完成后 [Read →] 跳到 PaperDetailPage
5. 既有 PaperList / PaperDetail UX 不破
6. `npm run build` 0 TS error
7. 既有 pytest ≥ 241 passed

## 不在范围

- ❌ Subscription 切到 DB（YAML 保留）
- ❌ 多账号 / 多用户
- ❌ 高级 schedule（cron 表达式编辑器，先用 daily/weekly preset）
- ❌ ingest 后批量编辑（如自定义标签）
- ❌ Sub history view（"上次运行" 只显示最近一次时间戳）

## 风险
- **YAML 写回保留注释**：`PyYAML` 默认会丢注释；用 `ruamel.yaml` 保留（已在依赖里？没有则加）
- **PDF 上传 multipart**：DRF 默认支持 `MultiPartParser`
- **chain job 错误处理**：extract 失败时不要继续 interpret；用 jobs.py 的 status 字段判断
- **arxiv id 校验**：format `\d{4}\.\d{4,5}` 正则 + try sources/pdf_fetcher（已有）
- **URL 安全**：限定 https + arxiv.org 域 / 或允许任意但仅 PDF（content-type 校验）
